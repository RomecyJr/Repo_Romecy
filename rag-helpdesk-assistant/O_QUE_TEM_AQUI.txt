🎯 OBJETIVO DESTA PASTA:
   Chatbot inteligente que responde dúvidas usando documentação interna

📝 EXPLICAÇÃO SIMPLES:
   Já ligou pro suporte e ficou esperando? Este projeto cria um
   assistente virtual que lê seus manuais/FAQs e responde perguntas
   automaticamente, como se fosse um atendente humano!

🔧 O QUE FAZ:
   ✓ Lê documentos (PDFs, FAQs, manuais)
   ✓ Entende perguntas em linguagem natural
   ✓ Busca resposta na base de conhecimento
   ✓ Responde de forma conversacional

💻 TECNOLOGIA USADA:
   → Python/FastAPI (servidor web)
   → LangChain (framework de IA)
   → ChromaDB (banco de dados vetorial)
   → RAG (Retrieval Augmented Generation)

📂 ESTRUTURA DE ARQUIVOS:

   📁 app/
      ├─ main.py ...................... Servidor da API
      ├─ rag.py ....................... Lógica da IA
      └─ kb/
         └─ faq.txt ................... Base de conhecimento

   📁 tests/
      └─ test_health.py ............... Testes automatizados

   📄 Dockerfile ....................... Para rodar em container
   📄 requirements.txt ................. Dependências Python
   📄 README.md ........................ Manual completo

🎓 PARA INICIANTES:

   RAG = "Busca inteligente + ChatGPT"

   Diferença do ChatGPT normal:
   - ChatGPT → Sabe coisas gerais da internet
   - RAG → Sabe sobre SUA empresa, SEUS documentos

   É como ter um funcionário que decorou todos os manuais!

═══════════════════════════════════════════════════════════════════════

📖 ANALOGIA DO DIA A DIA:

   Imagine um bibliotecário super inteligente:

   VOCÊ: "Como resetar senha do email?"

   CHATBOT:
   1. Procura em todos os manuais (base de conhecimento)
   2. Encontra seção relevante
   3. Resume a resposta de forma clara
   4. Responde: "Acesse configurações > segurança > resetar senha"

   Tudo em 2 segundos!

═══════════════════════════════════════════════════════════════════════

🎯 COMO FUNCIONA (PASSO A PASSO):

   1. INDEXAÇÃO (fase inicial):
      - Bot lê todos os documentos
      - Divide em pedaços pequenos
      - Salva no ChromaDB

   2. PERGUNTA DO USUÁRIO:
      - "Como imprimir em preto e branco?"

   3. BUSCA:
      - Procura nos documentos indexados
      - Encontra 3 trechos mais relevantes

   4. GERAÇÃO:
      - IA lê os trechos encontrados
      - Escreve resposta clara e direta

   5. RESPOSTA:
      - "Vá em Arquivo > Imprimir > Configurações > Preto e Branco"

═══════════════════════════════════════════════════════════════════════

🔑 CONCEITOS-CHAVE:

   RAG = Retrieval (Busca) + Augmented (Aumentada) + Generation (Geração)

   → RETRIEVAL: Busca documentos relevantes
   → AUGMENTED: Usa documentos como contexto
   → GENERATION: IA gera resposta baseada no contexto

═══════════════════════════════════════════════════════════════════════

💡 DIFERENCIAL:

   ❌ Chatbot comum: Respostas fixas e limitadas
   ✅ RAG Assistant: Entende contexto e adapta respostas

   ❌ Busca normal: Retorna documentos inteiros
   ✅ RAG: Extrai e resume só o necessário
